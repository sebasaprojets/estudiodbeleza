# Espaço Vip Studio de Beleza — instruções para o Claude

- Site estático: `index.html`, `css/style.css`, `js/main.js` (sem build). Publicado via GitHub Pages a partir da branch padrão.
- **Sempre que o usuário pedir uma alteração no site, faça commit e push para o GitHub logo após concluir e testar a mudança**, sem precisar perguntar.
- Converse com o usuário em português.
- Use a skill `ui-ux-pro-max` para decisões de design (fontes, cores, acessibilidade, responsivo).
- Número do WhatsApp e mensagens prontas ficam no objeto `WHATSAPP` no início de `js/main.js`.
- Teste desktop (1440px) e celular (390px) antes de enviar.
